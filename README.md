Mini Projects Repository
This repository contains two separate mini projects:

1.OOP Mini Project (Java) – located in src/com.krishna/miniproject
2.Dart Mini Project – located in the dart/ directory

1. OOP Mini Project (Java):

location:src/com.krishna/miniproject

Description:
This project demonstrates Object-Oriented Programming concepts including:

- Classes and Objects
- Inheritance
- Encapsulation
- Polymorphism

How to Run:

1. Open the project in IntelliJ IDEA / Eclipse / VS Code with Java extension.
2. Ensure JDK 8+ is installed.
3. Navigate to the main class file located in:
  src/com.krishna/miniproject/Main.java
Run:
javac Main.java
java Main

2. Dart Project:
location:
Dart/

Description:
This folder contains Dart code demonstrating:

- Functions
- Classes & Objects
- Basic I/O operations

How to Run:
1. Ensure Dart SDK is installed.
2. Open terminal inside the dart/ folder.

Run:
dart run filename.dart
